## 🚀 How to Use

### 1️⃣ Get the files

**Option A: Download as ZIP**

Click the green **Code** button on GitHub → **Download ZIP** → extract it.

**Option B: Clone with Git**


### 2️⃣ Open the folder in VS Code

```bash
code .
```

### 3️⃣ Open any PDF

Click a `.pdf` file in the VS Code explorer. To read it **inside VS Code**, install the extension below. 👇

## 🧩 Install the PDF Viewer Extension in VS Code

VS Code cannot display PDFs by default. Install the **vscode-pdf** extension to read them directly in the editor.

| | |
|---|---|
| **Extension name** | vscode-pdf |
| **Author** | tomoki1207 |
| **Extension ID** | `tomoki1207.pdf` |

### Method 1: From the Extensions panel (easiest)

1. Open VS Code.
2. Click the **Extensions** icon in the left sidebar (or press `Ctrl + Shift + X`).
3. In the search bar, type **`vscode-pdf`**.
4. Find **vscode-pdf** by **tomoki1207** and click **Install**.
5. Done ✅. Click any PDF file and it opens right inside VS Code.

### Method 2: From the terminal

```bash
code --install-extension tomoki1207.pdf
```

### Method 3: Quick Open

1. Press `Ctrl + P`.
2. Paste this command and press **Enter**:

```text
ext install tomoki1207.pdf
```

---

## ✅ Quick Check

After installing, open a PDF from the `TD/` or `TP/` folder. If you can see the document in a VS Code tab, everything works. If not, reload VS Code with `Ctrl + Shift + P` → **Developer: Reload Window**.
